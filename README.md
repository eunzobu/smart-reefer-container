# AI 기반 리퍼컨테이너

컨테이너 환경 모니터링과 예지정비를 결합한 프로젝트입니다. 화물 적재 전에 설비 상태를 확인하고, 운송 중 환경과 이상 정보를 사용자에게 전달하는 것을 목표로 했습니다.

## 본인 역할

팀장으로 일정과 기능별 진행 상황을 관리했습니다. 센서 데이터가 서버와 데이터베이스를 거쳐 앱에 전달되는 연동 과정과 통합 시험을 담당했습니다.

## 주요 구성

- 온도, 습도, 이산화탄소 데이터 수집과 모바일 상태 확인
- 적재 품목에 따른 환경 추천
- 설비 시계열 데이터를 이용한 이상 탐지와 예지정비 기능 설계
- GPS를 이용한 위치 정보 연계

## 문제 해결: 앱에서 센서 값이 보이지 않는 현상

서버와 데이터베이스에는 값이 저장됐지만 Android 앱에는 표시되지 않았습니다. 수집값, 서버 수신값과 저장값을 순서대로 비교해 해당 구간의 정상 동작을 확인했습니다.

이후 Node-RED의 발행 Topic과 앱의 구독 Topic이 서로 다른 것을 확인했습니다. Topic 명명 규칙과 센서 식별자를 통일한 뒤 앱 화면까지 값이 전달되는 것을 확인했습니다.

## 공개 범위

현재는 프로젝트 설명 문서입니다. 실행 코드와 원본 평가 자료는 포함하지 않았습니다. 예지정비의 최종 모델, 검증 조건과 성능은 평가 자료를 확인한 뒤 추가할 예정입니다.
