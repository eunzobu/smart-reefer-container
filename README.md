# AI 기반 리퍼컨테이너 환경 제어 및 유지보수 시스템

컨테이너의 환경 측정, 내부 영상, 자동 배수와 정비 안내를 모바일 앱에 연결한 IoT 시스템입니다. 화물을 싣기 전 상태 확인부터 운송 중 이상 감지와 정비 요청까지 하나의 흐름으로 구성했습니다.

**담당 역할:** 팀장으로 일정과 기능별 진행 상황을 관리하고, 센서 → 서버 → DB → Android 앱의 연동과 통합 시험을 담당했습니다. 앱에서 센서값이 보이지 않는 문제를 데이터 경로별로 추적해 MQTT Topic 불일치를 해결했습니다.

## 시스템 구조

![리퍼컨테이너 서비스 구성도](reefer-architecture.jpg)

ESP32가 온습도, 공기질, 진동과 수위 데이터를 수집합니다. Raspberry Pi는 장치 제어와 서버 게이트웨이를 담당하고, AWS 서버와 MQTT를 통해 앱 및 데이터베이스와 연결합니다. ESP32-CAM은 내부 영상 확인에 사용했습니다.

## 구현 내용

| 기능 | 동작 |
| --- | --- |
| 센서 모니터링 | ESP32와 Raspberry Pi에서 측정하고 Grafana에서 실시간 확인 |
| 내부 영상 | ESP32-CAM 영상 스트리밍을 서버 및 앱과 연결 |
| 자동 배수 | 수위 감지 시 릴레이와 모터를 작동하고 침수 경고 전달 |
| 컨테이너 등록 | QR 인식과 서버 등록, 회원가입 및 로그인 연동 |
| 상태 점검 | 센서 데이터를 바탕으로 장비 이상 여부를 판별 |
| 정비 안내 | GPS 위치를 활용해 가까운 수리 항만 안내 |

## 서비스 흐름

사용자는 로그인 후 운송 정보와 컨테이너를 등록합니다. 적재 전 상태를 점검하고, 운송 중에는 온습도와 센서 상태를 확인합니다. 이상 발생 시 경고 화면과 관련 센서를 확인하고, 필요한 경우 정비 항만을 선택해 요청을 전달하도록 구성했습니다.

![컨테이너 등록부터 이상 경고와 정비 안내까지의 모바일 화면](reefer-app.jpg)

*논문 원고에 수록된 모바일 화면 흐름. 각 화면의 연결 순서와 예외 상황을 보여줍니다.*

## 환경 추천과 상태 점검

적재 품목에 맞는 목표 환경을 산출하기 위해 Random Forest와 MLP 기반 회귀를 활용한 환경 추천을 설계했습니다. 상태 점검은 현재 센서 반응을 바탕으로 이상 여부를 판단하고, 사용자 경고와 정비 안내로 연결합니다.

## 문제 해결: MQTT Topic 불일치로 인한 앱 수신 오류

1. 센서 수집값과 서버 수신값을 비교했습니다.
2. DB 저장까지 정상임을 확인해 문제 구간을 앱 연동으로 좁혔습니다.
3. Node-RED 발행 Topic과 앱 구독 Topic의 불일치를 확인했습니다.
4. Topic 명명 규칙과 센서 식별자를 통일하고 화면까지 값이 전달되는지 확인했습니다.
